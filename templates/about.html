О приложении

Data Engineer Matrix — веб-приложение для визуализации, управления и развития матрицы компетенций: дерево навыков, графы, литература, импорт/экспорт и бэкапы источников.

Источник данных — единый файл в каталоге data/sources (по умолчанию matrix.json), а контент страниц обновляется через API и интерфейсные формы.
